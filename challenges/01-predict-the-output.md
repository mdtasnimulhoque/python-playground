# Challenge: Predict the output 🎯

**Rule:** Try to answer before running the code. Write down what you think each line displays.

## Round 1 — Warm-up

```python
print(3 + 4)
print("3" + "4")
```

## Round 2 — Variable detective

```python
lives = 3
lives = lives - 1
print(lives)
```

## Round 3 — Spot the difference

```python
word = "ha"
print(word * 2)
print(word + word)
```

## Round 4 — Explain, don't guess

```python
number = 5
print(number + 1)
print("number" + "1")
```

For each round: predict the exact output, run the code, then explain any difference between your prediction and the result.
