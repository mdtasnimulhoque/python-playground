# Python Playground — Assessment Pack

This pack adds short checkpoint quizzes and the initial design for the end-of-course assessment. It is designed to be copied into the existing `python-playground` repository without replacing your current lesson files.

## Add these files to your repository

Copy the `quizzes/` and `assessments/` folders into the root of your existing `python-playground` folder. If VS Code asks whether to merge folders, choose to merge; do not replace your lesson files.

## What's included

- `quizzes/lesson-00-computers-and-code.md` — concepts from Lesson 0
- `quizzes/lesson-01-make-python-speak.md` — concepts from Lesson 1
- `quizzes/lesson-02-values-and-experiments.md` — concepts from Lesson 2
- `quizzes/lesson-03-variables-are-labels.md` — a starter quiz for Lesson 3
- `assessments/final-assessment-blueprint.md` — the planned final assessment, scoring and leaderboard rules
- `assessments/level-0-checkpoint-test.md` — a draft test covering the first beginner lessons, with answers kept in a separate file
- `assessments/level-0-checkpoint-answer-key.md` — answers and explanations; keep this out of any public quiz interface

## Design rule

Questions should assess understanding, not reward memorizing the exact wording of lesson text. Mix prediction, explanation, debugging, code writing and practical application. Keep the answer key separate from the learner-facing test.
