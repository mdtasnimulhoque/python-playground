# Curriculum map

The goal is a coherent path from absolute beginner to advanced, practical Python. A topic is complete only when it has explanations, examples, practice, and checks—not merely a heading in this roadmap.

## First Steps — from zero

1. What code is; running Python; `print()`
2. Values, strings, numbers, and comments
3. Variables and naming
4. Input, output, and type conversion
5. Arithmetic and comparison
6. Boolean logic
7. `if`, `elif`, and `else`
8. `while` and `for` loops
9. Strings and common operations
10. Lists and indexing
11. Dictionaries, tuples, and sets
12. Functions, parameters, and return values
13. Scope and decomposition
14. Errors and debugging
15. Files and paths
16. Modules, imports, and virtual environments
17. Exceptions
18. A first tested command-line project

## Builder Path — write dependable programs

- Problem decomposition and pseudocode
- List/dict comprehensions
- Mutability, identity, and copying
- Sorting, searching, and algorithmic complexity
- File formats: CSV, JSON, and text
- Testing with `unittest` or `pytest`
- Debugging strategy and tracebacks
- Classes, objects, composition, inheritance, and dataclasses
- Type hints and static checking
- Logging, configuration, and command-line arguments
- Git, GitHub, code review, and documentation
- Packaging and dependency management

## Deep Dive — understand Python

- Iterables, iterators, and generators
- Decorators and closures
- Context managers
- Custom exceptions
- Descriptors and properties
- Dunder methods and Python's data model
- Async programming: `async` / `await`
- Concurrency and multiprocessing fundamentals
- Profiling, memory, and performance
- Regular expressions
- Protocols, generics, and advanced typing
- Packaging, environments, and reproducible builds
- Selected Python internals

## Creator Lab — choose a direction

- Automation and scripting
- Web APIs and backend development
- Data analysis and visualization
- Machine learning and AI
- Scientific computing
- Testing tools and developer productivity
- A capstone chosen by the learner

## Assessment philosophy

Each substantial unit should include a prediction question, a no-copy practice exercise, a debugging task, a retrieval review that revisits earlier topics, a practical application, and tests or a clear rubric where appropriate.

Advanced modules will be released progressively. This roadmap is a plan, not a claim that all content already exists.
