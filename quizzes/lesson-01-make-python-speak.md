# Checkpoint Quiz — Lesson 1: Make Python Speak

**When to take it:** After completing Lesson 1
**Suggested time:** 5–8 minutes
**Total:** 10 points
**Goal:** Understand how `print()` works, predict program output, and write simple Python instructions.

Try to answer independently before running any code.

## Questions

### 1. Predict the output — 2 points

What will this program display?

```python
print("Hello!")
print(2 + 3)
```

Write both output lines in the correct order.

**Scoring:** 1 point for each correct line.

### 2. Text or calculation? — 1 point

Which line displays the text `2 + 3` rather than calculating the sum?

* A. `print(2 + 3)`
* B. `print("2 + 3")`
* C. `print(2) + print(3)`
* D. `print("2" + 3)`

### 3. Explain `print()` — 1 point

In your own words, explain what `print()` does in these examples.

A clear, simple sentence is enough.

### 4. Find and fix the error — 2 points

What's wrong with this line, and how would you fix it?

```python
print("I am learning Python.)
```

Write the corrected line of Python and briefly explain your correction.

**Scoring:**

* 1 point for correcting the code.
* 1 point for explaining what was wrong.

### 5. Predict before running — 2 points

Without running the program, predict its output.

```python
print(10 + 5)
print("10 + 5")
print(10)
```

Write all three output lines in order.

**Scoring:** Award credit for each correctly predicted line, up to 2 points.

### 6. Make it your own — 2 points

Write two Python instructions:

1. One that displays a message of your choice.
2. One that displays the result of a simple calculation.

**Scoring:**

* 1 point for a working message instruction.
* 1 point for a working calculation instruction.

## Reflection — Optional, ungraded

Which feels easier now: displaying a message, displaying a calculation, or predicting what code will do? Explain briefly.

This reflection is for your own learning and does not affect your score.

## Score guide

* **9–10:** Strong understanding of the main ideas.
* **7–8.5:** Good progress; review the questions you missed.
* **5–6.5:** You're learning. Revisit the relevant examples and try again.
* **Below 5:** Review Lesson 1 at your own pace, then attempt the quiz again.

A score is feedback, not a judgment of your potential. The goal is to understand the code, not simply memorize answers.
