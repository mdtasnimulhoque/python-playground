# Checkpoint Quiz — Lesson 2: Values and Experiments

**When to take it:** After completing Lesson 2
**Suggested time:** 8–10 minutes
**Total:** 10 points
**Goal:** Understand Python values and types, predict output, and investigate errors.

Try to answer each question before running the code. Explain your reasoning where requested.

## Questions

### 1. Match the value to its type — 2 points

Match each value with its correct type: `int`, `float`, `str`, or `bool`.

1. `42`
2. `4.2`
3. `"42"`
4. `False`

**Scoring:** 0.5 points for each correct match.

### 2. Predict the output — 1 point

What will this program display?

```python
print(7 + 3)
print("7" + "3")
```

Write both output lines in order.

**Scoring:** 0.5 points for each correct line.

### 3. Investigate with `type()` — 1 point

What will these lines display?

```python
print(type(6 / 2))
print(type("hello"))
```

Write the output as Python displays it.

**Hint:** The `/` operator produces a `float` in Python 3, even when the result is a whole number.

**Scoring:** 0.5 points for each correct output.

### 4. Explain the difference — 1 point

Why do `25` and `"25"` look similar when printed but represent different types?

Explain the difference in your own words.

### 5. Debug it — 2 points

This code raises an error:

```python
age = "18"
print(age + 2)
```

Answer both parts:

1. Why does the error happen?
2. Write a corrected version that displays the numerical result `20`.

**Scoring:**

* 1 point for explaining the type mismatch.
* 1 point for a working correction.

### 6. New experiment — 1 point

Predict the output:

```python
print("ha" * 3)
print(4 * 3)
```

Write both lines in order.

**Scoring:** 0.5 points for each correct line.

### 7. True or false? — 1 point

The expression `5 > 3` evaluates to the Boolean value `True`.

Choose **True** or **False**, then briefly explain your answer.

**Scoring:** 0.5 points for the correct choice and 0.5 points for a valid explanation.

### 8. Explain your process — 1 point

When Python displays an unexpected result, name two things you can do to investigate it.

For example, you might use a Python feature or perform a small experiment. Give two distinct actions.

**Scoring:** 0.5 points for each useful, distinct action.

## Reflection — Optional, ungraded

Which experiment in this lesson surprised you most? What did it teach you about Python?

This reflection is for learning, not grading.

## Score guide

* **9–10:** Strong understanding of the main ideas.
* **7–8.5:** Good progress; review the concepts behind missed questions.
* **5–6.5:** You're building understanding. Repeat a few experiments and try again.
* **Below 5:** Revisit the lesson at your own pace before retaking the quiz.

Your score is feedback, not a judgment of your ability. Understanding why an answer works is more valuable than memorizing it.
