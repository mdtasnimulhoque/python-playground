# Checkpoint Quiz — Lesson 3: Variables Are Labels

**When to take it:** After completing Lesson 3
**Suggested time:** 8–10 minutes
**Total:** 10 points
**Goal:** Create variables, update values, follow naming rules, and debug common mistakes.

Try to predict the output before running the code.

## Questions

### 1. Predict the output — 1 point

```python
score = 10
print(score)
```

What will the program display?

### 2. Update a variable — 1 point

```python
score = 10
score = 15
print(score)
```

What is displayed, and why?

### 3. Choose a valid variable name — 1 point

Which option is a valid Python variable name?

* A. `2score`
* B. `student score`
* C. `student_score`
* D. `class`

Choose one answer and briefly explain why it is valid.

### 4. Assignment or comparison? — 2 points

Explain the difference between `=` and `==` in Python.

Then identify which operator belongs in each example:

1. `score ___ 10` — assign the value `10` to `score`.
2. `score ___ 10` — check whether `score` equals `10`.

**Scoring:**

* 1 point for explaining the difference.
* 0.5 points for each correct operator.

### 5. Predict carefully — 1 point

```python
points = 4
points = points + 3
print(points)
```

What will be displayed? Explain how Python calculates the updated value.

### 6. Find and fix the name — 1 point

What's wrong with this code?

```python
student_name = "Mina"
print(studentname)
```

Write a corrected version that displays `Mina`.

### 7. Make your own variable — 1 point

Create a variable named `favourite_language`, give it a string value of your choice, and print it.

Your code should run without errors.

### 8. Explain the metaphor — 2 points

Why can a variable be thought of as a label associated with a value? What does this metaphor help you understand?

Explain in your own words. A simple example is welcome.

**Scoring:**

* 1 point for explaining that a variable name refers to or is associated with a value.
* 1 point for explaining how the name helps you use or update that value in a program.

## Reflection — Optional, ungraded

What is one variable-naming mistake you will watch out for when writing Python?

This reflection is for your learning and does not affect your score.

## Score guide

* **9–10:** Strong understanding of the main ideas.
* **7–8.5:** Good progress; review any mistakes and try a few extra examples.
* **5–6.5:** You're building understanding. Practice assignment, reassignment, and variable names.
* **Below 5:** Revisit Lesson 3 and attempt the quiz again at your own pace.

The goal is not just to get the right answer. It is to understand why Python behaves that way.
