## `01` / The idea

Python Playground is a free, open-source learning experience for complete beginners, curious builders, and programmers who want to understand Python deeply.

This is **more than a pile of notes or a video playlist**. The goal is to help you predict what code will do, experiment with it, explain the idea in your own words, practise deliberately, debug mistakes, and build things that work.

> **Never coded before? Start here.** You do not need a computer-science background.

## `03` / The learning loop

<div align="center">

**HOOK** → **PREDICT** → **EXPLORE** → **UNDERSTAND** → **PRACTISE** → **RETRIEVE** → **BUILD**

</div>

- **Hook** — begin with a question, mystery, or useful result.
- **Predict** — make a guess before running the code.
- **Explore** — run a small example, then change it.
- **Understand** — explain the idea in plain language.
- **Practise** — solve a challenge with graduated hints.
- **Retrieve** — revisit earlier concepts without notes.
- **Build** — combine what you know in a meaningful mini-project.

Progress matters more than streaks. The goal is understanding and independence—not copying code without knowing what it does.

## `04` / Learning paths

| Path | Explore |
|---|---|
| 🌱 **First Steps** | Setup, output, values, variables, input, conditions, loops, functions, and core data structures |
| 🧰 **Builder Path** | Files, errors, modules, testing, debugging, object-oriented programming, and problem-solving |
| 🔬 **Deep Dive** | Iterators, generators, decorators, context managers, typing, async programming, performance, packaging, and Python internals |
| 🎨 **Creator Lab** | Automation, web development, data, AI/ML, and scientific-computing projects |

The roadmap is evolving. Not every advanced module is written yet; the project aims to be transparent about what is available today and what is still in progress. See [CURRICULUM.md](CURRICULUM.md).

## `05` / Your first program

Install Python 3 from [python.org](https://www.python.org/downloads/) or use a reputable browser-based Python environment if you cannot install software yet.

Create `hello.py`:

```python
print("Hello, future programmer!")
print("I can teach a computer to follow instructions.")
```

Run it from your terminal. Depending on your system, use `python hello.py` or `python3 hello.py`.

## `07` / What we care about

- **Clarity:** beginner-friendly explanations without talking down to learners.
- **Practice:** reasoning and experimentation, not just copying.
- **Access:** free materials designed to work on modest devices and connections.
- **Honesty:** correct examples, visible prerequisites, and transparent project status.
- **Respect:** mistakes are evidence for learning, not a verdict on ability.
- **Inclusion:** make the first step into programming feel possible for more people.
