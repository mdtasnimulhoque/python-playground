# Python Playground 🐍✨

**Make people curious enough to begin, confident enough to continue, and capable enough to build without us.**

Python Playground is a free, open-source learning experience for complete beginners, curious builders, and programmers who want to understand Python deeply.

This is not a wall of notes or a video playlist. Lessons help you **predict, experiment, explain, practice, debug, and build**.

## Start here

**Never coded before? You're in the right place.** You do not need a computer-science background.

1. Begin with [Lesson 1: Make Python speak](lessons/00-zero-to-coder/01-make-python-speak.md).
2. Try the tiny experiments before reading the explanations.
3. Make a prediction before running code.
4. Change the examples and observe what happens.
5. Attempt the challenge before looking at the solution.

Already know some Python? Use the [curriculum map](CURRICULUM.md) to find a suitable starting point. Skipping ahead is fine—but check the prerequisites.

## The learning loop

1. **Hook** — a question, mystery, or useful result to spark curiosity.
2. **Predict** — guess what the code will do.
3. **Explore** — run and modify a small example.
4. **Understand** — explain the idea in plain language.
5. **Practice** — solve a challenge with graduated hints.
6. **Retrieve** — revisit earlier ideas without notes.
7. **Build** — use the idea in a small, meaningful project.

Points and badges may add a little fun, but understanding and independence matter more than streaks.

## Learning paths

- **First Steps:** setup, output, values, variables, input, conditions, loops, functions, and core data structures.
- **Builder Path:** files, errors, modules, testing, debugging, object-oriented programming, and problem-solving.
- **Deep Dive:** iterators, generators, decorators, context managers, typing, async programming, performance, packaging, and Python internals.
- **Creator Lab:** automation, web development, data, AI/ML, and scientific computing projects.

See [CURRICULUM.md](CURRICULUM.md) for the roadmap. This is an evolving course: not every advanced module is written yet, and we label work honestly.

## Run your first program

Install Python 3 from [python.org](https://www.python.org/downloads/) or use a reputable browser-based Python environment if you cannot install software yet.

Create a file named `hello.py`:

```python
print("Hello, future programmer!")
print("I can teach a computer to follow instructions.")
```

Run it with your Python installation. Depending on your system, the command may be `python hello.py` or `python3 hello.py`.
