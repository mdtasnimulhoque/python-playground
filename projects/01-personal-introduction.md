# Mini-project: Your personal introduction 🌟

**Concepts:** `print()`, strings, numbers, variables · **Difficulty:** Beginner

## Goal

Make a tiny program that introduces a fictional character or yourself.

## Requirements

Your program should store a name, a hobby, and a number in variables; display a friendly introduction; and include one calculation.

Example:

```python
name = "Alex"
hobby = "drawing"
stars = 3

print("Hello! My name is", name)
print("I enjoy", hobby)
print("I collected", stars, "stars today.")
print("Tomorrow I hope to collect", stars + 2, "stars.")
```

Your output can be different. The point is to adapt the idea, not copy this exact example.

## Level up

1. Add a variable for a favourite book, game, or subject.
2. Print a two-line message.
3. Change a variable and observe how the output changes.
4. Explain which parts are values and which parts are variable names.
